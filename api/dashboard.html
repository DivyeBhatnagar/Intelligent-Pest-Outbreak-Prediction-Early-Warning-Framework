Data Sources & System Health

Service status, data provenance, and known limitations.

API Health
Data Sources
  • 🌾 ICAR Surveillance Dataset — 35,499 records, 12 centres, 23 pests, 1992–2011
  • 🌦️ Weather — Open-Meteo Live API (free, no key required); fallback to seasonal baseline
  • 🗺️ Map Tiles — © OpenStreetMap contributors (free, no API key)
  • 📚 ETL Thresholds — TNAU Crop Pest Threshold & Control guidelines
  • 💾 Database — SQLite (WAL mode), artifacts/pest_framework.db
⚠️ Known Limitations
  • • Primary model predicts next-week outbreak occurrence, not daily or seasonal forecasts.
  • • Auxiliary models have low accuracy (multi-pest: 48.75%, severity: 33.50%) and should be used for exploratory analysis only.
  • • Full-dataset accuracy (97.83%) reflects training-set coverage, not generalization ability.
  • • Weather data is fetched from Open-Meteo; fallback to seasonal baseline when offline.
  • • SHAP values show model contribution, not causal agricultural evidence.
  • • No image-based pest classification is implemented or planned.
Auxiliary Model Information

These models are separate from the primary outbreak predictor and serve exploratory analysis only.
